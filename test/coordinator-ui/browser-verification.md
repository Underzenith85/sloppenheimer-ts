# Coordinator primitive browser verification (#304)

The application entry displays sample fixtures without requesting fleet data. Run
`pnpm --filter @sloppenheimer/coordinator-ui dev` and open the printed localhost URL.
Structural and interaction regressions run with `pnpm test test/coordinator-ui`.

Verified on 2026-09-06 using Chromium 145.0.7632.6, Playwright 1.58.2 and
axe-core/playwright 4.11.1, installed in a temporary directory outside the workspace.
No browser tooling dependency is required by the application.

| Check                         | Procedure and observed result                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| ----------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Structure and actual contrast | Run axe WCAG 2 A/AA and 2.1 AA against the rendered page and open dialog. No violations, including color-contrast checks. Repeat at 320 CSS px wide.                                                                                                                                                                                                                                                                                                                                                                        |
| Keyboard focus                | Tab from the page start through controls. A solid 3px outline appears. Unavailable controls remain reachable and display their reason; Enter and Space do not activate them.                                                                                                                                                                                                                                                                                                                                                |
| Targets                       | Measure each rendered button's bounding box: both dimensions are at least 44 CSS px.                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| Dialog                        | Focus Review sample; Enter and Space open the named dialog. Its title and description are associated. Initial focus is on Unavailable confirmation; Shift+Tab wraps to Close, and Tab wraps back. Escape and Close both dismiss and restore focus to Review sample.                                                                                                                                                                                                                                                         |
| Forced colors                 | Emulate forced-colors active. All five status labels and disabled reasons remain visible; keyboard focus has a solid outline. The page also passes the structural axe audit. System colors determine contrast in this mode.                                                                                                                                                                                                                                                                                                 |
| Reduced motion                | Emulate prefers-reduced-motion reduce. Computed button transition duration is 0s. No animation conveys required information.                                                                                                                                                                                                                                                                                                                                                                                                |
| Zoom and reflow               | At a 1280×900 viewport, apply 200% and 400% CSS zoom in Chromium. The page has no horizontal overflow; the dialog stays within the viewport and scrolls to its Close control. Separately test a 320×720 CSS px viewport. Native browser tab zoom also passes at 200% (640×450 CSS px) and 400% (320×225 CSS px), using a temporary extension calling `chrome.tabs.setZoom`. At both scales the dialog fits, Close is reachable, and Escape restores focus. Screenshots inspected in default, forced-colors, and 400% modes. |

For manual reproduction, use browser accessibility emulation for forced colors and reduced
motion. Repeat browser toolbar zoom at 200% and 400% on the target browser. In the dialog, confirm that all content is
reachable by scrolling and that the focused control stays visible. The modal uses a percentage
maximum height against its fixed containing block so its height stays bounded under CSS zoom.

The DOM harness does not measure contrast, geometry or native keyboard navigation. The real
browser checks above supplement those tests; they do not establish screen-reader compatibility
across every browser/assistive-technology combination.
