# Symphony conformance matrix

This matrix targets the upstream Symphony SPEC Sections 17 and 18 as retrieved on 2026-08-29.
`pnpm test:conformance` is deterministic and needs no network or credentials. The default
`pnpm test` includes both core and extension conformance and explicitly excludes
`test/real-integration`. Run the opt-in profile with `pnpm test:real-integration`.
